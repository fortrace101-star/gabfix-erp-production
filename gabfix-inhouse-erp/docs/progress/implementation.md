### Role model (server `ROLES` const in `server/routes/permission-matrix.ts`)

| Role          | Scope                                  | Capabilities                                                       |
| ------------- | -------------------------------------- | ------------------------------------------------------------------ |
| `owner`       | everything (and can delegate)          | everything; `manage_access`, `manage_employees`                    |
| `manager`     | `app_scope` grant/revoke; manage staff | `manage_access`, `manage_employees`, `view_reports`, `assign_crew` |
| `sales`       | read-only finance/customer view        | `view_reports`, `assign_crew`                                      |
| `technician`  | field job execution                    | `assign_crew`, `view_reports`                                      |
| `laundry`     | laundry fulfilment                     | `assign_crew`, `view_reports`                                      |
| `storekeeper` | store/materials                        | `assign_crew`, `view_reports`                                      |
| `accountant`  | finance/timesheets                     | `assign_crew`, `view_reports`                                      |
| `csr`         | customer support                       | `handle_leads`, `review_feedback`, `view_reports`                  |

### Portal role dropdown (customer support panel)

The in-house employee portal (`gabfix-inhouse-erp/src/pages/index.tsx`, `src/components/PortalBell.tsx`) now exposes a 5-option `<select>` in the topbar dropdown. Choosing a role recomputes KPIs from `GET /api/data` and swaps the `visibleJobs` slice, so the _same_ logged-in staff screen can preview each role's dashboard.
